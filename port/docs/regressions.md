# port 重建回归记录

本文件只记录跨移植反复出现、容易被再次漏掉的问题，以及对应的预防或验证方式。普通缺陷由修复提交和测试留存，不在这里堆叠。

## 记录规则

- 只有跨版本重建或重复发生的移植坑才记录。
- 每条记录包含：问题与触发条件、根因、预防或验证、状态。
- 记录要指向可重跑的行为检查，不把一次性日志或临时观察当成回归。
- 没有复发风险的历史问题可以删除，保持本文件短小。

## 新增流程

1. 先确认问题会在下一次上游或 DSH 基线变更时重复出现。
2. 写出最小触发条件和失败现象。
3. 增加可复跑的测试或脚本检查。
4. 在这里登记问题和验证入口；修复细节留在提交和代码中。

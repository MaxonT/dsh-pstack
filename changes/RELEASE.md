## 概要

本次发布修复旧会话修复页在 DSH Desktop 0.2.2-rc.5 自带 Node 24.21.0 上漏检多帧 Zstandard 会话日志的问题。修复前扫描显示 0 个会话，排队修复也不会改写日志。升级后重新扫描并修复受影响的旧会话即可。安装本版不需要先升级 DSH。

## 修复

- **旧会话修复页漏检多帧日志**：之前修复页把整个 `session.v4.jsonl.zstd` 一次性解压，Node 24.21.0 只返回第一个 Zstandard 帧，扫描读不到后面的 `poteto/mode` 事件，显示 0 个会话，排队修复也不会改写日志。现在按帧解码完整日志，能列出并修复受影响的旧会话。
  - 影响：升级后打开配置弹窗的「修复」页重新扫描，选中要迁移的旧会话并修复，然后重启 DSH。
